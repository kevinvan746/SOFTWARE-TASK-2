# THE PLAN
At the start of this project, I wanted to make a fun text-based RPG based on Solo Leveling. My first idea was to let the player fight enemies, level up and move through different stages. Before I started coding, I planned the main features I wanted, like battles, quests, an inventory, shops and different locations.

To get ideas for the game, I watched the Solo Leveling anime. This helped me understand the story, the characters and the different places in the series. I used these ideas to create locations 

I also got some help from a Google software engineer. They showed me how to organise my code by using classes instead of putting everything into one big section. They explained that this would make the code easier to read and easier to improve later. Their advice helped me plan my game before I started writing the code.

# Creating Characters
Creating the Characters The first thing I made was the character system. I created a Character class that stored the health, attack and defence for every character. Then I made separate Player and Enemy classes so each one could have its own special features while still sharing the same basic code.

Using classes made my code much cleaner and easier to understand. It also made it easier to add more features later without changing lots of code.

# Adding Levels
Next, I added a level system so the player could become stronger by defeating enemies. Every time the player earns enough experience, they level up and gain more health, attack, defence and mana.

# Making the Battle System
The battle system was one of the biggest parts of the project. Players can choose to attack, use a potion or run away.

I used Python's random feature so the damage changes each time someone attacks. This makes every battle different and more fun to play.

When an enemy is defeated, the player earns experience, coins and sometimes a potion. This gives players rewards for winning battles.

# Testing The Game
While making the game, I tested it often to make sure everything worked properly. I checked that the menus worked, battles ended correctly and rewards were given after defeating enemies.

When I found bugs, I fixed them by reading Python documentation and searching for information online. This helped me understand the problems and improve my coding skills.

# FINAL REFLECTION
I am happy with how my game turned out. It started as a simple idea but slowly became a full text-based RPG with battles, levels, quests, shops, items and different locations.

Watching the Solo Leveling anime helped me come up with ideas for the story and locations. The advice from a Google software engineer also helped me organise my code better by using classes. Because of this, it was much easier to add new features as I kept working on the project.

This project helped me learn more about Python, classes, problem solving and testing. If I kept working on the game, I would add more weapons, armour, stronger bosses, extra locations and a save feature so players could continue their adventure later.
